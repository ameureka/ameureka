### 💡 工程主张 (Engineering Philosophy)

> **“从提示词技巧走向 Harness 系统工程：拒绝靠自然语言 Prompt 赌输出概率，用前置契约规格、执行状态机与自动化门禁，构建确定性交付的智能体闭环。”**

专注于探索大模型能力如何深度融入生产级研发工作流与企业级业务交付。核心工作聚焦于三项关键突破：
1. **执行边界约束**：通过严格的输入契约与执行状态机，杜绝 Agent 的无序漂移；
2. **证据可信追溯**：使所有研究分析与代码交付物均具备可审计的证据链与哈希指纹；
3. **沉淀为基础设施**：将资深工程经验固化为可复用的门禁脚本、原子技能（Skills）与自动化工具链。

## 📦 核心工程深度剖析

### 01 · 体系教程：大模型工程化与生产治理 — [Tutorials-for-the-Harness-series](https://github.com/ameureka/Tutorials-for-the-Harness-series)

<img src="https://raw.githubusercontent.com/ameureka/ameureka/main/files/Harness%20Engineering%20Architecture.png" alt="Harness Engineering Architecture" width="100%" />

- **体系定位**：覆盖大模型从认知升级到生产落地的完整进阶教程，直击提示词不可控、黑盒幻觉、上下文膨胀三大核心瓶颈。
- **理论基座 📐** —— 确立“输入限制 + 状态跟踪 + 边界门禁”的 Harness 工程框架，以可量化的工程约束替代不确定的自然语言祈祷。
- **治理架构 🛡️** —— 实践三权分立机制（执行 Agent、对抗评估 Eval、主干状态审计 Controller），实现无人值守场景的安全闭环。
- **生产实践 🚀** —— 深度剖析 上下文工程（Context Compression/Compaction）、MCP 协议标准对接、以及生产级 APM/可观测性实践。
- [教程全景目录](https://github.com/ameureka/Tutorials-for-the-Harness-series) · [CC-BY-4.0 协议](https://github.com/ameureka/Tutorials-for-the-Harness-series/blob/main/LICENSE) · [路线图说明](https://github.com/ameureka/Tutorials-for-the-Harness-series/blob/main/README.md)

### 02 · AI 研发全栈工程化规范 — [open-source-ssd](https://github.com/ameureka/open-source-ssd)

<img src="https://raw.githubusercontent.com/ameureka/ameureka/main/files/Reliable%20AI%20Delivery.png" alt="Reliable AI Delivery" width="100%" />

- **核心主张**：建立 Specification-State-Distill (SSD) 研发体系，为 AI 编程助手提供无歧义的输入、状态追踪与准出标准。
- **流程设计 🎭** —— 任务分级分解、确定性停止条件（Stop Conditions）、界面设计规范与标准化发布 Runbook。
- **工程实现 🛠️** —— Next.js / TypeScript 全栈脚手架，搭配严格的 Server Action 架构边界与自动化检查门禁脚本。
- **反思沉淀 🤝** —— 包含多期复杂业务重构的复盘记录，深入探讨机制设计与生产环境真实交付之间的工程落差。

### 04 · 研究工作流与证据治理 — [open-waza-agent](https://github.com/ameureka/open-waza-agent)

<img src="https://raw.githubusercontent.com/ameureka/ameureka/main/files/Evidence%20to%20Insight.png" alt="Evidence to Insight" width="100%" />

- **核心主张**：构建可核验的深度研究工作流，让复杂长文研报的每一个论点均与事实源头强绑定。
- **证据建模 🎭** —— 显式登记数据源、推导逻辑与交付物，利用 SHA-256 内容哈希锁定审阅版本。
- **自动化边界 🛠️** —— 专家智能体聚焦于逻辑推理，Python 确定性工具负责证据登记断言、排版质量核验与多源合并。
- **可复现入口 🤝** —— 提供完备的离线样例、失败路径拦截测试，并原生支持人工批注与修订保护机制。
